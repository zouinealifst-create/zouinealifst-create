## 👋 À propos

Étudiant en **1ère année du Cycle Ingénieur en Génie Informatique** à la **FST Settat**, je me spécialise dans la **conception de systèmes backend fiables et bien architecturés** : modélisation UML, architecture en couches, API REST et bases de données relationnelles.

Au-delà du code, je m'intéresse à tout ce qui fait tourner un système en production : **réseaux, administration Linux et cloud AWS**. J'explore aussi l'**IA appliquée** (RAG, agents multi-agents, LLM) pour construire des produits utiles.

- 🎓 Cycle Ingénieur Génie Informatique, FST Settat (2025 – 2028)
- 🔭 En ce moment : agents IA vocaux, RAG et architectures backend en couches
- 🌱 J'approfondis : Java EE, Spring Boot, cloud AWS
- 💼 **Je recherche un stage PFA de 1 à 2 mois**
- 🗣️ Langues : Arabe (natif), Français (B2), Anglais (B1)
